# 🎵 SoundCloud BPM Organizer for Runners

A web application that analyzes the BPM (Beats Per Minute) of your SoundCloud liked tracks and organizes them by running pace.

## Features

- ✅ Fetches liked tracks from any SoundCloud profile
- ✅ Real BPM analysis using Node.js backend (no CORS issues!)
- ✅ Filter tracks by BPM range
- ✅ Pre-configured running pace presets (Walking, Jogging, Running, Sprinting)
- ✅ Export playlists as text files
- ✅ Real-time progress tracking

## Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)
- SoundCloud Client ID ([Get one here](https://soundcloud.com/you/apps))
